# Open issues

Unclaimed work is tracked in GitHub Issues, not in this file, so the tracker and
the repository cannot drift:

https://github.com/Cygnus-aid-disbursement/cygnus-contracts/issues

Each issue keeps its difficulty label (`good first issue`, `intermediate`,
`advanced`) and area labels. To claim one, comment on it. See
[CONTRIBUTING.md](CONTRIBUTING.md) for how the labels work and the rules a pull
request must meet.
